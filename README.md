# Secure Data Transmission using DWT & Image Scrambling

## Overview
This project implements a two-layer security system combining cryptography and steganography to securely transmit data over the internet.

## Features
- Data hiding using Discrete Wavelet Transform (DWT)
- Image scrambling for enhanced security
- Protection against unauthorized data access

## Technologies Used
- MATLAB / Python 
- Image Processing Techniques

## Outcome
Improved data confidentiality and secure transmission of sensitive information.
